# Eclipse 설치 폴더

**폴더:** Eclipse 설치 폴더 (예: `C:\eclipse_egov{버전}`)

이 폴더 하나만 고르면 그 밑을 뒤져서 자동으로 찾습니다:

- 컴포넌트 정의 파일 (`WebSquareConfig.xml`) — Property·Event 목록에 씁니다
- wpack 변환기 (`w-pack/index.js` 또는 `standalone_wpack-win.exe`) — 화면 저장 시 JS로 변환합니다
- API 문서 폴더 (`index.html`·`$p`·`WebSquare.*`) — Script 탭 자동완성에 씁니다 (선택)

플러그인 폴더 이름은 설치본마다 달라도 괜찮습니다. 자동으로 못 찾은 항목이 있으면 그 기능을 쓸 때 알림으로 알려주며, 거기서 개별 파일·폴더를 직접 지정할 수 있습니다.

---

선택하면 사용자 설정에 저장되어 모든 프로젝트에 적용됩니다. 다시 바꾸려면 F1 → **WebSquare5: 환경 설정**
